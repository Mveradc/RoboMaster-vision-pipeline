# RoboMaster Vision Pipeline

Object-detection pipeline for RoboMaster, developed for the GISD / PIDS course at UPM.

## Structure

- `week1/` – data preparation
  - `video2frames.ipynb`: extract frames from videos
  - `eda.ipynb`: exploratory data analysis
  - `data_aug.ipynb`: data augmentation
- `week2/` – model training and evaluation
  - `train.ipynb`: training
  - `test.ipynb`: evaluation
